# Day 1: Cryptographic Hashing

## Objective
Understand the avalanche effect in blockchain using SHA-256 hashing.

## What I did today
* Wrote a Go script (`main.go`) to hash transaction data.
* Demonstrated how changing a single character ("5 ETH" to "6 ETH") completely randomizes the resulting hash, ensuring blockchain immutability.

## How to run the code
`go run main.go`
