# Day 5: Introduction to Solidity

## Objective
Write and deploy a basic smart contract to understand state variables and EVM execution.

## What I did today
* Created `SimpleStorage.sol`, my first Ethereum smart contract.
* Learned the structure of a `.sol` file (`pragma`, `contract`, state variables).
* Differentiated between state-changing functions (which cost Gas) and `view` functions (which are free).
* Deployed and interacted with the contract using the Remix IDE simulated blockchain environment.
